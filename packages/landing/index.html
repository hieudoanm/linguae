Built for privacy and simplicity

A single static binary that does one thing well — identify languages — without phoning home.

Runs fully offline

Inference happens in-process inside the Rust binary. No sockets, no telemetry, no accounts — safe for air-gapped machines.

Trained from scratch

A character-level CNN trained with Candle on Tatoeba, WiLI-2018, and a curated word dataset. No pretrained weights to trust or audit.

Fast and small

Character-level encoding keeps the model compact. Detection of a sentence completes in milliseconds on CPU.

Flexible input

Pass text as an argument, a file with --file, or pipe it through stdin — it composes with standard Unix tools.

Confidence and JSON

--confidence prints per-language scores and --format json emits structured output for scripts.

Batch processing

Detect languages across whole files or streams line by line — built for corpus-scale workloads.

How it works

From raw text to a language code in three steps.

  1. 1

    Normalize

    Text is lowercased, stripped of diacritics variation, and mapped onto a fixed character vocabulary.

  2. 2

    Encode

    Characters become indices fed into a CharCNN — small kernels capture local n-gram patterns, global pooling summarizes the text.

  3. 3

    Classify

    The model emits a probability per language; the CLI prints the top ISO 639-3 code, or scores with --confidence.

Install and run

Requires Rust 1.85+. No Python runtime needed for the CLI.
