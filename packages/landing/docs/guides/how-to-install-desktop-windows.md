# How to install the Linguae desktop app on Windows

For 64-bit Windows.

## Option 1: MSI installer

1. Open the [downloads page](https://hieudoanm.github.io/linguae/downloads/) and
   download **Windows** under **Desktop** —
   `desktop-linguae-x86_64-pc-windows-msvc.msi`.
2. Double-click the `.msi` and follow the installer wizard.

## Option 2: setup executable

Download `desktop-linguae-x86_64-pc-windows-msvc-setup.exe` instead and run it —
it is the NSIS installer equivalent.

## SmartScreen

The installer is unsigned, so Windows SmartScreen may warn on first run. Choose
**More info → Run anyway**.

## Verifying

Launch Linguae from the Start menu.
